# SLINK // Secure Self-Hosted File Transfer

Slink is a lightweight, production-ready, and security-focused file sharing system designed for VPS environments.

## 🚀 Installation

Ensure you have Python 3.10+ and `python3-venv` installed.

```bash
# Clone the repository
git clone https://github.com/ERM073/slink.git
cd slink

# Run the installation script
bash install.sh
```

## ⚙️ Running the Server

Start the server using the virtual environment:

```bash
./.venv/bin/python main.py serve
```

## 🛠 CLI Usage

```bash
./.venv/bin/python main.py <file-path> [options]
```

## 🧨 Uninstallation

```bash
bash uninstall.sh
```
